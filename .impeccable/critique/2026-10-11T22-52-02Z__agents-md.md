## Priority Issues

- **[P1] Architectural Token Fragmentation Across 55+ Static Files**
  - **Why it matters**: In a zero-build static site, inlining CSS variables across 55+ files leads to token drift. For example, `DESIGN.md` mandates `#0f172a` for primary text, whereas `index.html` declares raw `--text-primary: #000000;`, conflicting with the Craft Floor ban on raw black.
  - **Fix**: Mandate and link a centralized `assets/css/tokens.css` across all hub and topic pages.
  - **Suggested command**: `/impeccable document`

- **[P1] Omission of URL State Synchronization in the Widget Contract**
  - **Why it matters**: Researchers, clinicians, and policy analysts must be able to cite and share specific calculation outputs. Without standardized URL query parameter or hash state serialization, calculators cannot be bookmarked or shared in specific states.
  - **Fix**: Add an 8th clause to Section 5: *"8. State Synchronization & Deep-Linking: Serialize non-default simulator inputs into URL parameters/hash anchors so specific calculation scenarios can be bookmarked and shared."*
  - **Suggested command**: `/impeccable harden`

- **[P2] Underspecified Assistive Technology Feedback for Dynamic Calculators**
  - **Why it matters**: While Section 6 requires `aria-live="polite"`, continuous range sliders can flood screen readers with noise or omit unit context.
  - **Fix**: Standardize an accessible calculator pattern: debounce live announcements to the `change` event, provide an accessible summary region, and require `aria-valuetext` with localized units (e.g. `aria-valuetext="150 Kilowatt"`).
  - **Suggested command**: `/impeccable audit`

- **[P2] Missing Canonical Semantic HTML Skeleton for Widgets & Fallbacks**
  - **Why it matters**: The 7-item contract is conceptually clear, but contributors lack a standard HTML structure for intermediate causality disclosures (`<details>`) and `<noscript>` fallback tables.
  - **Fix**: Embed a concise 15-line canonical HTML skeleton in Section 5 demonstrating compliant semantic tags (`<form>`, `<output>`, `<details class="calc-causality">`).
  - **Suggested command**: `/impeccable layout`

- **[P3] Absence of Lateral Cross-Topic Compendium Discovery Navigation**
  - **Why it matters**: The linking architecture is strictly vertical (`index.html` ↔ `topics/<topic>.html` ↔ subpages). Readers on cardiology compendiums have no standard lateral navigation to related diagnostics without returning to the root index.
  - **Fix**: Define a standard "Related Compendiums" editorial cluster band in Section 1 for all topic hubs.
  - **Suggested command**: `/impeccable layout`

Android Scoped MediaStore

Uses atomic IS_PENDING=1 transactions on Android 10–15. Files appear in your system Gallery and Music players only after full muxing and SHA-256 verification.

content://media/external/video/media

Zero-Copy 8K AV1 & FLAC Muxing

Merges separate high-bitrate video and lossless audio streams directly into MKV, MP4, or WebM containers using -c copy without re-encoding or battery drain.

ffmpeg -i video.av1 -i audio.opus -c copy out.mkv

Under the Hood

          
4-Stage Stream Ingestion Pipeline

          

            Inspect how suravidl resolves manifests, schedules concurrent range workers, muxes bitstreams without re-encoding, and commits to storage.
          

        


        

          
          
          
          
        


        
        

          

            
01. Asynchronous Manifest & Signature Resolution

            

              Parses HLS (.m3u8), MPEG-DASH (.mpd), and direct progressive endpoints using an isolated Kotlin/Python extractor pool. Automatically selects the highest dynamic range and audio fidelity streams matching user constraints.
            

            
    
              
  • ✓ DNS-over-HTTPS (DoH) resolution to prevent ISP manifest poisoning.
    • 
              
  • ✓ Decoupled video/audio track scoring (AV1 > VP9.2 > HEVC > H.264).
    • 
              
  • ✓ Automatic cookie & session token injection for authenticated streams.
    • 
            

          

          

            
Extractor Output142 ms

            
[extractor] Resolved manifest: 24 adaptive representations
[select] Video: id=401 (3840x2160p60, av01.0.13M.10, HDR10)
[select] Audio: id=251 (opus, 48000Hz, 160kbps, 2.0ch)

          

        


        
        

          

            
02. Concurrent Byte-Range Worker Pool

            

              Divides each stream into 16 MB byte-range blocks across 8 non-blocking HTTP/2 coroutines. If a CDN node stalls on one socket, work-stealing reallocates the remaining byte range to the fastest active worker.
            

            
    
              
  • ✓ Adaptive work-stealing eliminates tail-latency stalls on final chunks.
    • 
              
  • ✓ Persistent resume journal (.suravidl.part) survives network drops.
    • 
              
  • ✓ Optional external aria2c daemon handoff via JSON-RPC.
    •

03. Zero-Copy FFmpeg Stream Muxing

            

              Invokes the embedded native FFmpeg library to interleave video, audio, chapter markers, and subtitle tracks directly into the target container with zero video/audio transcoding overhead.
            

            
    
              
  • ✓ Bitstream pass-through (-c:v copy -c:a copy) preserves 100% quality.
    • 
              
  • ✓ FastStart MOOV atom relocation (-movflags +faststart) for instant playback.
    • 
              
  • ✓ Embeds high-res thumbnail art and SponsorBlock chapter metadata.
    • 
            

          

          

            
FFmpeg PipelineZero-Copy

            
ffmpeg -y -i video.av1 -i audio.opus -i subs.en.vtt \
  -map 0:v:0 -map 1:a:0 -map 2:s:0 \
  -c:v copy -c:a copy -c:s srt -movflags +faststart output.mkv

          

        


        
        

          

            
04. Atomic Scoped MediaStore Commit

            

              Verifies the output container integrity and atomically flips Android's MediaStore.MediaColumns.IS_PENDING flag from 1 to 0, making the file immediately visible to all gallery and media apps.
            

            
    
              
  • ✓ Zero invasive MANAGE_EXTERNAL_STORAGE permission required.
    • 
              
  • ✓ Automatic MIME type & duration indexing for instant gallery previews.
    • 
              
  • ✓ Emits completion broadcast intent for third-party automation apps.
    • 
            

          

          

            
Android ContentResolverAPI 29–35

            
val values = ContentValues().apply { put(IS_PENDING, 0) }
resolver.update(mediaUri, values, null, null)
// Committed -> /storage/emulated/0/Movies/suravidl/output.mkv

FAQ

          
Frequently Asked Technical Questions

        


        

          

            
              How does suravidl handle Android 10–15 storage permissions?
              +
            
            

              suravidl uses the native Android Scoped MediaStore API with IS_PENDING atomic flags. Media is written to isolated cache segments during muxing and revealed to public Movies/suravidl or Music/suravidl collections only after checksum verification, requiring zero invasive broad-storage permissions.
            

          


          

            
              Does suravidl re-encode video or audio streams by default?
              +
            
            

              No. By default, suravidl executes zero-copy stream pass-through (-c copy) via its embedded FFmpeg pipeline, preserving 100% of the source video and audio bitstreams without generation loss or CPU thermal throttling.
            

          


          

            
              Which architecture does suravidl support on Android?
              +
            
            

              suravidl officially releases an optimized 64-bit ARM64-v8a APK for Android 8.0+ devices, delivering direct hardware acceleration for Snapdragon, Google Tensor, Dimensity, and Exynos processors.

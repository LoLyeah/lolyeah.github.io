High-performance media ingestion, built for speed and privacy. Ingesti media berkecepatan tinggi, dirancang untuk kecepatan dan privasi.

suravidl is an open-source media downloading application and stream extraction engine created by LoLyeah. Combining an ergonomic Android mobile interface with a high-performance Python ingestion core, version 0.39.8 delivers concurrent fragment range chunking, automatic gallery indexing with scoped storage compliance, lossless format remuxing, and SponsorBlock filtering with complete privacy. suravidl adalah aplikasi pengunduh media dan mesin ekstraksi stream sumber terbuka yang dikembangkan oleh LoLyeah. Menggabungkan antarmuka mobile Android yang ergonomis dengan inti ingesti Python berkinerja tinggi, versi 0.39.8 menghadirkan chunking range fragmen konkurensi, indeks galeri otomatis dengan kepatuhan scoped storage, remuxing format lossless, dan filter SponsorBlock dengan privasi penuh.

CLI Flags & Engine Options (v0.39.8) Argumen CLI & Opsi Mesin (v0.39.8)

Reference parameters for the underlying suravidl engine and terminal execution. Filter options instantly with the search bar. Referensi parameter untuk inti suravidl engine dan eksekusi terminal. Saring opsi secara instan dengan bilah pencarian.

-f, --format <SPEC>

Selects video and audio stream quality (e.g. "bv*[height<=1080]+ba/b").

Memilih kualitas video dan audio yang akan diunduh.

--concurrent-fragments <N>

Number of parallel chunk workers (e.g. 4 or 8) for range streams to saturate connection.

Jumlah worker paralel (misal 4 atau 8) untuk mempercepat pengunduhan fragmen.

--sponsorblock-remove <CATEGORIES>

Segment types to cut on keyframes: sponsor, intro, outro, selfpromo.

Kategori segmen video yang dipotong pada keyframe: sponsor, intro, outro.

-x, --extract-audio --audio-format <opus|flac|mp3>

Discards video stream and extracts standalone lossless audio track.

Membuang trek video dan mengekstrak audio berkualitas tinggi.

--embed-subs --sub-langs <LANGS>

Downloads timed subtitle tracks and muxes them as soft streams into MP4/MKV.

Mengunduh file subtitle dan menyematkannya ke dalam kontainer video.

--keep-in-gallery [FLAG]

Triggers Android Scoped MediaStore broadcast so saved media appears in gallery.

Memicu siaran MediaStore Android agar media langsung muncul di galeri.

-o, --output <TEMPLATE>

Custom directory and filename template for saved media files.

Templat direktori dan penamaan file untuk media yang disimpan.

--embed-metadata --embed-thumbnail

Embeds chapter marks, uploader details, and high-DPI album art into container atoms.

Menyematkan penanda bab, informasi pembuat, dan gambar cover ke file.

--cache-dir <PATH>

Designates location for staging chunk fragments with automatic garbage collection.

Menentukan lokasi penyimpanan fragmen sementara dengan pembersihan otomatis.

--limit-rate <RATE>

Bandwidth ceiling (e.g. "5M", "500K") to prevent saturating shared connections.

Batas kecepatan unduh agar tidak menghabiskan bandwidth jaringan bersama.

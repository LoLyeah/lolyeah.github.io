Teleradiologi SATUSEHAT & Tele-Ekspertise Terdistribusi: DICOM Cloud Nasional, Regulasi 3-SIP, & Simulator Bandwidth.

Dengan lebih dari 60% dari 514 kabupaten/kota di Indonesia mengalami kelangkaan dokter spesialis radiologi, inisiatif teleradiologi nasional melalui National Imaging Data Repository (NIDR) SATUSEHAT Kemenkes merevolusi akses diagnostik. Dokumen teknis ini membedah arsitektur integrasi Docker DICOM Router, pemetaan HL7 FHIR ImagingStudy, benturan hukum 3-SIP lintas provinsi pasca-UU 17/2023, kedaulatan data medis UU PDP 27/2022, serta simulator latensi jaringan darurat stroke.

Spesifikasi Teknis

Pipeline End-to-End SATUSEHAT DICOM Cloud & NIDR

Digital Transformation Office (DTO) Kemenkes RI menetapkan standar interoperabilitas antara PACS rumah sakit lokal dengan National Imaging Data Repository (NIDR). Berikut adalah siklus transaksi enam tahap dari paparan radiasi modalitas hingga rilis laporan diagnostik tervalidasi sertifikat elektronik.

01 On-Premise Faskes

Transmisi C-STORE Modalitas

Modalitas (CT, MRI, DR X-ray) menyelesaikan pemindaian dan menginisiasi protokol DICOM C-STORE ke gateway lokal RS pada port 104 atau 11112. File memuat metadata klinis dan Accession Number SATUSEHAT yang di-generate melalui ServiceRequest SIMRS.

C-STORE-RQ (Modality → Local PACS)
SOPClassUID: 1.2.840.10008.5.1.4.1.1.2
AccessionNo: SATU-2026-SR-98124
02 Edge Gateway

Docker DICOM Router & Kompresi

Kontainer Docker DICOM Router resmi Kemenkes yang dipasang on-premise di RS mencegat citra masuk. Router melakukan kompresi lossless JPEG-LS (rasio ~3:1), memverifikasi tag kepatuhan privasi, serta menyematkan UUID Pasien SATUSEHAT berbasis NIK terenkripsi.

Compression: JPEG-LS Lossless (3.2x)
Payload: 600 MB → 187 MB
Outbound: mTLS HTTPS :443 (Port 104 Blocked)
03 Kemenkes Cloud

NIDR Cloud Object Storage

Partisi citra terkompresi diunggah ke National Imaging Data Repository (NIDR) melalui API S3 terenkripsi AES-256. Server fisik ditempatkan di Pusat Data Nasional (PDN Cikarang/Batam) guna memenuhi kewajiban kedaulatan data medis UU PDP 27/2022.

Bucket: nidr-kemenkes-prod-enc
Encryption: SSE-KMS / AES-256-GCM
Location: Sovereign Indonesian DC (PDN)
04 Interoperabilitas

Pemetaan FHIR ImagingStudy

Engine FHIR SATUSEHAT memetakan metadata menjadi resource ImagingStudy. Menghubungkan Series Instance UID, kode modalitas DICOM, anatomi tubuh SNOMED CT, dan endpoint WADO-RS untuk rendering streaming tanpa mengunduh seluruh file mentah.

Resource: ImagingStudy (FHIR R4)
Endpoint: dicom-wado-rs / studies/...
Codes: SNOMED CT + LOINC 24725-4
05 Zero-Footprint Web

Viewer Diagnostik WADO-RS

Dokter spesialis radiologi konsultan membuka citra melalui web viewer zero-footprint (OHIF / Cornerstone3D) terautentikasi OAuth2 SATUSEHAT. Irisan citra di-render secara streaming progresif (WADO-RS frames), sehingga radiolog dapat mulai membaca dalam hitungan detik.

Protocol: DICOMweb WADO-RS
Render: Progressive WebGL 16-bit GSDF
Auth: JWT Bearer Token (Expires 30m)
06 Otorisasi Medikolegal

DiagnosticReport & Tanda Tangan BSrE

Hasil ekspertise akhir disusun sebagai HL7 FHIR DiagnosticReport berstruktur LOINC/RADLEX, ditandatangani secara kriptografis menggunakan sertifikat elektronik BSrE (BSSN). Ekspertise langsung sinkron ke aplikasi SATUSEHAT Mobile pasien dan dashboard IGD perujuk.

Resource: DiagnosticReport (FHIR R4)
Signature: BSrE (BSSN) X.509 Cryptographic
Sync: SATUSEHAT Mobile Patient Timeline
Medikolegal & Kebijakan

Dilema 3-SIP, Kedaulatan Data UU PDP, & Matriks Tanggung Jawab

Meskipun teknologi cloud DICOM memungkinkan seorang dokter spesialis radiologi di Jakarta atau Surabaya membaca CT scan dari Maluku dalam dua menit, payung hukum positif Indonesia menetapkan batasan ketat mengenai legalitas praktik, tanggung jawab malpraktik, dan kerahasiaan data pasien.

Batasan Statuter 3-SIP (UU 17/2023)

Pasal 263-265 UU Kesehatan No. 17/2023

Dokter spesialis di Indonesia dibatasi maksimal memiliki 3 Surat Izin Praktik (SIP). Pertanyaan hukum krusial: Apakah membaca teleradiologi untuk 15 RSUD di pelosok terhitung sebagai 15 tempat praktik? Berdasarkan regulasi telemedisin Kemenkes, radiolog bertindak di bawah SIP faskes asalnya jika formatnya adalah tele-ekspertise konsultatif antarfaskes, namun ekspertise primer untuk faskes tanpa radiolog organik menuntut relaksasi regulasi SIP Khusus Telemedisin Nasional.

Catatan Krusial: Jangan pernah menandatangani ekspertise primer untuk klinik tanpa MoU Institusional Telemedisin resmi yang mengklasifikasikannya sebagai layanan konsultasi antarfaskes.

Tripartit Tanggung Jawab Medikolegal

Radiografer • Dokter Perujuk • Radiolog

Jika terjadi missed diagnosis perdarahan atau stroke iskemik hiperakut, tanggung jawab dibagi secara tegas: (1) Radiografer bertanggung jawab atas artefak gerakan, kesalahan parameter kVp/mAs, atau pemotongan batas anatomis; (2) Dokter Perujuk bertanggung jawab atas anamnesis klinis keliru, alergi kontras, atau keterlambatan transfer pasien; (3) Radiolog Pembaca bertanggung jawab penuh atas kesalahan interpretasi lesi yang tampak secara objektif pada monitor diagnostik.

Klausul Wajib: Laporan teleradiologi wajib mencantumkan klausul penafian teknis apabila kualitas citra atau artefak mengaburkan interpretasi (cth: 'Kualitas citra suboptimal akibat artefak gerak berat').

Kedaulatan Data & UU PDP 27/2022

Pasal 4, Pasal 56 UU PDP No. 27 Tahun 2022

Citra DICOM dan ekspertise radiologi diklasifikasikan sebagai Data Pribadi yang Bersifat Spesifik dalam UU PDP. Pasal 56 melarang transfer data medis keluar wilayah yurisdiksi Indonesia tanpa persetujuan bilateral setara. Platform teleradiologi yang menyimpan data citra di server cloud luar negeri tanpa tenant lokal di Indonesia terancam denda hingga Rp 50 miliar dan pembatalan izin operasional faskes.

Uji Kepatuhan: Pastikan seluruh vendor cloud/PACS komersial beroperasi di zona data center lokal Indonesia (cth: Jakarta region) dan menerapkan enkripsi mTLS end-to-end.

Realitas Tarif Klaim BPJS INA-CBGs

Sistem Paket INA-CBGs • Margin Jasa Baca B2B

BPJS Kesehatan tidak memiliki pos tarif terpisah untuk 'Jasa Baca Teleradiologi'. Seluruh biaya interpretasi jarak jauh harus dipotong dari paket tarif klaim INA-CBGs rumah sakit perujuk. RSUD Tipe C dan D di daerah umumnya mengontrak pihak ketiga swasta dengan tarif berkisar Rp 30.000 hingga Rp 65.000 per pemeriksaan CT—menciptakan tekanan volume tinggi di mana radiolog dituntut membaca hingga puluhan kasus per shift.

Pergeseran Masa Depan: Kemenkes mengkaji skema remunerasi tele-ekspertise standar nasional dalam program rujukan KJSU untuk menjamin kompensasi yang adil dan bermartabat.

Aman dalam Golden Hour Klinis

Standar Workstation Mandiri

Standar Monitor Diagnostik & Ergonomi Remote Workstation

Membaca teleradiologi dari workstation rumah mewajibkan kepatuhan terhadap standar DICOM Part 14 GSDF. Monitor komersial biasa atau tablet tanpa kalibrasi dapat menyamarkan mikro-kalsifikasi payudara, fraktur halus tanpa pergeseran, atau edema sitotoksik dini pada infark serebri.

Kalibrasi DICOM Part 14 GSDF

Mata manusia menangkap kontras luminansi secara non-linear. Standar GSDF memastikan setiap kenaikan nilai piksel menghasilkan perubahan persepsi visual yang setara. Ekspertise primer menuntut monitor medis tersertifikasi (Barco, Eizo, Totoku) dengan fotometer kalibrasi otomatis.

Luminance: Min 400–500 cd/m²
Ambient Room Lighting: < 50 lux

Ambang Batas Resolusi Spasial

Matriks CT dan MRI beresolusi 512x512 piksel, sehingga cukup optimal pada monitor 2MP hingga 3MP. Namun, rontgen digital toraks (DR) dan mamografi digital mewajibkan monitor minimal 3MP dan 5MP (pitch piksel di bawah 50 mikron) untuk mendeteksi mikrokalsifikasi keganasan.

Cross-sectional (CT/MRI): 2MP–3MP
Mammography / DR: 5MP Mandatory

iPad Pro & Teleradiologi Mobile

Layar tandem OLED pada iPad Pro terkini memiliki kontras luar biasa. Namun regulasi internasional dan Kemenkes hanya mengizinkan penggunaan perangkat tablet bergerak untuk triase darurat on-call di luar rumah sakit (cth: konfirmasi perdarahan stroke), bukan untuk pembacaan diagnostik primer rutin.

FDA Clearance: Mobile Triage Only

Model Ekonomi

Arketipe Praktik Masa Depan: Model Pendapatan Radiolog 2026–2035

Paradigma tradisional di mana dokter spesialis radiologi terikat secara eksklusif di ruang baca fisik satu rumah sakit bergeser menjadi tiga model praktik hibrida modern.

Model 01

Hub-and-Spoke Rumah Sakit Vertikal

Berbasis di rumah sakit rujukan nasional utama (RSUPN Cipto Mangunkusumo, RS Kanker Dharmais, RS Sardjito). Radiolog menghabiskan 40% waktu melakukan tindakan intervensi langsung dan 60% memimpin tele-ekspertise kasus sulit rujukan dari 30 RSUD binaan di Indonesia Timur via NIDR SATUSEHAT.

Stabilitas: Tinggi Karier Akademik
Model 02

Kolektif Tele-Ekspertise Mandiri

Kelompok 10–15 dokter spesialis radiologi konsultan membentuk entitas badan hukum kolektif yang mengontrak langsung jaringan RS swasta. Mereka membagi pembacaan berdasarkan kepakaran organ (CT Jantung, MRI Fetal, Cedera Olahraga MSK), menyediakan layanan sub-spesialis 24/7 tanpa perantara.

Remunerasi: Sangat Tinggi Kemandirian Finansial
Model 03

Praktik Fraksional Berbantuan AI

Radiolog bertindak sebagai validator ahli atas draft ekspertise awal yang dihasilkan algoritma AI. Kecepatan baca meningkat hingga 3x lipat untuk skrining rontgen toraks dan trauma tumpul, memungkinkan jadwal kerja fleksibel dari rumah dengan mitigasi hukum tanda tangan akhir.

Fleksibilitas: Maksimal Work-Life Balance

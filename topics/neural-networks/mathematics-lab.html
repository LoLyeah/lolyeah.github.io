Step-by-Step Backpropagation Derivation

A rigorous multivariable calculus walkthrough from scalar loss to batched weight tensor updates.

1. Layer Forward Propagation (Vector Form)

For layer $l \in \{1, \dots, L\}$ with weight matrix $W^{[l]} \in \mathbb{R}^{n_l \times n_{l-1}}$ and bias vector $b^{[l]} \in \mathbb{R}^{n_l}$:

z^{[l]} = W^{[l]} a^{[l-1]} + b^{[l]}
a^{[l]} = \sigma^{[l]}\left(z^{[l]}\right)

2. Output Sensitivity Definition ($\delta^{[L]}$)

We define the error sensitivity vector $\delta^{[l]} \equiv \frac{\partial \mathcal{L}}{\partial z^{[l]}}$. For output layer $L$ under Mean Squared Error loss $\mathcal{L} = \frac{1}{2}\|a^{[L]} - y\|^2$:

\delta^{[L]} = \frac{\partial \mathcal{L}}{\partial a^{[L]}} \odot \sigma'\left(z^{[L]}\right) = \left(a^{[L]} - y\right) \odot \sigma'\left(z^{[L]}\right)

Under Categorical Cross-Entropy loss with Softmax activation $\mathcal{L} = -\sum y_k \log a_k^{[L]}$, the Jacobian and derivative simplify elegantly to:

\delta^{[L]} = a^{[L]} - y \quad (Softmax + Cross-Entropy gradient cancellation)

3. Recursive Backward Sensitivity ($\delta^{[l]}$)

Applying the multivariable chain rule backwards through layer $l+1$ to pre-activation $z^{[l]}$:

\delta^{[l]} = \left(\frac{\partial z^{[l+1]}}{\partial a^{[l]}}\right)^T \frac{\partial \mathcal{L}}{\partial z^{[l+1]}} \odot \sigma'\left(z^{[l]}\right) = \left((W^{[l+1]})^T \delta^{[l+1]}\right) \odot \sigma'\left(z^{[l]}\right)

The transpose $(W^{[l+1]})^T$ projects error gradients from dimension $n_{l+1}$ back to dimension $n_l$.

4. Parameter Gradients & Mini-Batch Accumulation

Differentiating with respect to the trainable weight tensors and biases across a mini-batch of $m$ training samples:

\frac{\partial \mathcal{L}}{\partial W^{[l]}} = \frac{1}{m} \delta^{[l]} \left(a^{[l-1]}\right)^T \quad \in \mathbb{R}^{n_l \times n_{l-1}}
\frac{\partial \mathcal{L}}{\partial b^{[l]}} = \frac{1}{m} \sum_{i=1}^m \delta^{[l](i)} \quad \in \mathbb{R}^{n_l}

1. The Hessian Matrix & Condition Number $\kappa(H)$

Taylor expansion around local parameter vector $\theta$ expresses loss curvature in terms of the symmetric second-order partial derivative matrix $H \in \mathbb{R}^{P \times P}$:

ℒ(θ + Δθ) ≈ ℒ(θ) + ∇ℒ(θ)ᵀ Δθ + ½ Δθᵀ H Δθ
H_ij ≡ ∂²ℒ / (∂θ_i ∂θ_j)

The spectral decomposition $H = \sum_{k=1}^P \lambda_k q_k q_k^T$ defines the condition number:

κ(H) = λ_max(H) / λ_min(H)

In deep neural networks, $\kappa(H)$ frequently spans $10^4$ to $10^8$. To prevent divergent exploding updates along the stiff eigenvector $q_{\max}$, gradient descent step sizes must satisfy $\eta < 2/\lambda_{\max}$. Consequently, velocity along the shallow valley floor $q_{\min}$ is choked to $\eta \lambda_{\min} \le 2/\kappa(H) \ll 10^{-4}$, causing severe pathological oscillations across ravine walls.

2. Natural Gradient Descent & Fisher Information

Amari (1998) proved that Euclidean distance $\|\Delta\theta\|_2^2 = \sum \Delta\theta_i^2$ is an arbitrary artifact of parameterization. Rescaling weights changes Euclidean gradients without altering network output behavior.

Natural Gradient defines distance on the Riemannian statistical manifold of probability distributions $p_\theta(y \mid x)$ using Kullback-Leibler (KL) divergence:

D_KL(p_θ ‖ p_{θ + dθ}) ≈ ½ dθᵀ F dθ
F = 𝔼_{x, y ~ p_θ}[ ∇_θ log p_θ(y|x) · (∇_θ log p_θ(y|x))ᵀ ]

The Natural Gradient update direction is invariant to reparameterization:

Δθ_Nat = -η F⁻¹ ∇ℒ(θ)

Under negative log-likelihood loss, $F$ equals the expected Hessian $\mathbb{E}[H]$. Practical algorithms like K-FAC factor $F$ into layer Kronecker products $A_{l-1} \otimes S_l$, enabling tractable inversion without $O(P^3)$ computational scaling.

3. Frontier 2025–2026 Matrix Optimization: Muon

While AdamW normalizes updates coordinate-by-coordinate as independent 1D scalars ($\hat{m}_t / \sqrt{\hat{v}_t}$), neural weights are 2D linear operators $W \in \mathbb{R}^{d_{\text{out}} \times d_{\text{in}}}$. Coordinate-wise scaling ignores singular value spectrum geometry.

Muon (Jordan, Bernstein et al., 2024–2026) maintains momentum $M_t = \beta M_{t-1} + (1-\beta)G_t$, but normalizes the entire matrix to the nearest orthogonal matrix (polar factor):

𝒪(M) = M (Mᵀ M)⁻¹/² ⟹ ∀i: σᵢ(𝒪(M)) = 1

To bypass costly $O(d^3)$ SVD decompositions, Muon evaluates 5 iterations of Quintic Newton-Schulz polynomial iterations on GPU Tensor Cores:

X_{k+1} = a X_k + b (X_k X_kᵀ) X_k + c (X_k X_kᵀ)² X_k
a = 3.4445, b = -4.7750, c = 2.0315

Because Newton-Schulz consists purely of GEMMs running at >80% MFU with zero cross-socket synchronization stalls, Muon accelerates LLM pretraining convergence by ~30–40% over AdamW in frontier recipes.

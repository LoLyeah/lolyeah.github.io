Chinchilla & Inference-Optimal Scaling Laws

The mathematical relationship balancing parameters $N$, dataset tokens $D$, and compute budget $C$.

Chinchilla Compute-Optimal Frontier

Hoffmann et al. (DeepMind 2022) proved that for a given compute budget $C \approx 6 N D$, model parameters and training tokens should scale in equal proportion:

N_{opt} \propto C^{0.5}, \quad D_{opt} \propto C^{0.5} \implies D \approx 20 \times N

Prior models like GPT-3 (175B parameters trained on only 300B tokens = 1.7 tokens/param) were severely compute-suboptimal and parameter-bloated.

Inference-Optimal Over-Training

While Chinchilla optimizes training compute, real-world deployment is dominated by inference serving costs. Models like LLaMA-3 8B trained on 15 Trillion tokens (~1,875 tokens/param) deliberately violate Chinchilla to minimize parameter size and serving VRAM.

\text{Cost}_{total} = \text{Cost}_{train}(N, D) + Q_{queries} \times \text{Cost}_{infer}(N)

The Memory Wall & IO-Aware Kernel Tiling

Why modern GPUs spend more time waiting for memory transfer than performing mathematical matrix multiplication.

FlashAttention-1, 2, 3 Mechanics (Tri Dao)

Standard attention materializes intermediate matrices $S = Q K^T$ and $P = \text{Softmax}(S)$ in High Bandwidth Memory (HBM), resulting in $O(T^2)$ memory reads and writes. FlashAttention tiles the computation across fast on-chip SRAM cache ($~100 \text{ TB/s}$ bandwidth) using the online softmax trick:

m_{new} = \max(m_{prev}, m_{curr}), \quad \ell_{new} = e^{m_{prev}-m_{new}}\ell_{prev} + e^{m_{curr}-m_{new}}\ell_{curr}

By computing softmax incrementally without ever writing the $T \times T$ attention matrix back to HBM, FlashAttention reduces memory reads/writes from $O(T^2)$ to $O(T)$, yielding a 3× to 5× wall-clock speedup and enabling 128K+ context lengths.
